# Four-minute walkthrough

1. Launch the app. Observe the synthetic-profile warning, target Data Analyst role and unfinished objectives. Explain that the role catalogue is educational, not market data.
2. In Learner Profile set nickname, Python self-rating 4, study hours 6 and save. Open Career Roles to inspect required skills, weight, prerequisites and learning references.
3. Open Skill Gap Analysis. Explain current evidence versus claims, gap formula, normalized priority and foundation dependencies. Open Learning Roadmap, start an objective and save. Mark Python completed if present; otherwise select another available objective for the persistence demonstration.
4. Open Assessment / Practice, choose Python, intentionally answer both questions incorrectly and submit. Read the actual feedback and before/after estimate. In Gap Analysis Python now uses assessment evidence with estimate zero while the self-rating remains four. If Python was completed, it reopens as started. Its prerequisites/dependents cause the roadmap to recompute.
5. Open Adaptive Learning. Explain the recorded before/after levels, state bins, selected activity and baseline. Show simulated evaluation and the reward assumptions; these are not real learner outcomes.
6. Open Model Lab. Train if necessary, inspect Ridge and classification metrics, confusion matrix, split sizes, seed and class balance. Explain the synthetic generator and held-out preprocessing discipline. Inspect K-Means profiles as arbitrary groupings, not verified ability labels.
7. In Progress & Reports show the saved attempt, skill history, gap snapshots and download a CSV. Reload the app to demonstrate persistence. Settings reset remains disabled until deletion is confirmed.
