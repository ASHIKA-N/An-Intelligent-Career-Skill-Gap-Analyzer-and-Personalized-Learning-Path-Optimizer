# Dataset provenance

`catalogue.json`: manually curated educational requirements for four roles, sixteen reusable skills, two authored multiple-choice questions per skill, prerequisites, effort estimates, outcomes, practice tasks and public learning URLs. These are not hiring standards. Edit this file to maintain roles; `python data/build_catalogue.py` regenerates the initial catalogue and overwrites catalogue edits. Resource URLs are curated references, not live verified course inventory; availability is not checked at runtime.

`synthetic_assessments.csv`: generated by `python -m skillroute.ml` using NumPy seed 42. All 600 rows are synthetic independent learners, never real students. A beta-distributed latent proficiency generates noisy Python/statistics levels, prior performance and project counts. Future scores use a documented rule plus Gaussian noise (standard deviation 12). The model learns this artificial relationship. Mastery is derived from future-score bands. This is a software/evaluation demonstration, not evidence of real educational efficacy.

Replacement CSV columns: `learner_id` (unique opaque ID, no personal identifiers), `python` and `statistics` (0–5), `practice_hours` (1–80 weekly hours), `prior_score` (0–100), `projects` (0–30), `next_score` (0–100 future outcome), `mastery` (`developing` for <=45, `guided` for >45 and <=70, `independent` for >70). At least 100 records, all three classes with at least ten examples each; missing values, non-finite numbers, duplicated learner IDs and duplicate feature vectors are rejected. One record per learner prevents cross-split learner overlap. The owner must establish consent, temporal feature provenance and data rights; schema validation cannot prove these. UI upload limit is 2 MB. Uploaded text is never executed and no original upload is persisted.

Names and notes are excluded from model features. Targets and labels never enter feature columns. Scores and feature ranges are validated before splitting. To reproduce the public benchmark, rerun the default training command; no network needed.
